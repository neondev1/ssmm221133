This folder contains various "modules" of the interpreter which are used to
aid debugging. If you are only interested in playing with the interpreter, you
should use `main.s` (in the parent directory). If you want to browse the code
to look at implementation details, the files in this folder may be of help as
the code isn't just stuffed in one massive file.

Discussions of implementation details will be provided in the main README.

(Unfortunately, SM213 assembly does not support `%include` directives, so I
can't simply include these files in `main.s`.)
